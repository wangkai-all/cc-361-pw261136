Sealed Wire Vault

capture → seal → recompute, with the original packet pinned

Sources

Fictional feeds with real on-disk bytes. A capture seals exactly what one fetch returned; withdraw never deletes sealed bytes.

Sealed objects

Each object is one immutable byte stream: manifest digest identifies it, chunk list proves it, stream digest reproduces it.

Parse runs

Every run pins object + rule version. Stop can kill the worker process; resuming continues from the last committed byte offset.

Worker processes

The web server only records intent. Capture and parse run in separate OS processes you can start, stop, or kill here.

Process hygiene

Hard kill sends SIGKILL to the parse worker. The run stays running until its lease expires, then any worker resumes it from the checkpoint without duplicating records.
